Any KAREOKIE 的 YouTube 匯入來源擴充（protocol 1）。

安裝：下載下面的 any-kareokie-source-youtube-1.0.3.zip，在 Any KAREOKIE 的「設定 → 匯入來源 → 安裝來源…」選這個檔，或直接把 zip 拖進 App。

## 1.0.3

- 支援 Mac（Apple 晶片）：zip 裡多了 Mac 版執行檔，Mac 上會下載 `yt-dlp_macos`
- Windows 版的行為不變

---

- 裝好後就在背景從 GitHub（yt-dlp/yt-dlp）下載 yt-dlp（約 25～40 MB），之後每 3 天自動更新
- 沒有 Any KAREOKIE 的官方簽章，安裝時會顯示「未簽章」
- 使用前請先閱讀 TERMS.md：只能用來存取你有權使用的內容
